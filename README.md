# anihub

Термінальний застосунок для пошуку й перегляду аніме з озвученням або субтитрами. Працює на Linux, macOS і Windows.

- **9 джерел:** український anitube 🇺🇦, а також animego, yummy-anime, anilibria, animevost, dreamcast, hdrezka, sameband, anilibme
- **MyAnimeList:** серії зараховуються самі, статус Watching / Completed ставиться сам, оцінка, видалення зі списку, ваш список із фільтром за статусом
- **«Дивлюся»:** ваші тайтли з Watching, згори — ті, в яких вийшли нові серії
- **Профіль MyAnimeList:** статистика, останні оновлення, улюблене й друзі — ваш і будь-якого користувача; список аніме друга
- **Сповіщення:** нові сиквели, приквели, фільми й спешли до тайтлів з вашого списку, `a` — одразу в Plan to Watch
- **Онгоінги:** фільтр «Виходять / Анонси», тайтли з новими серіями піднімаються вгору
- **Субтитри:** мітка `СУБ` у варіантів з оригінальною доріжкою та субтитрами; якщо на сайті їх немає, `t` шукає той самий тайтл на інших сайтах
- **Постери** просто в терміналі, теми оформлення, миша й клавіатура, інтерфейс англійською та українською
- **Оновлення** однією командою: `anihub update`

## Встановлення

Потрібні дві речі:

1. **[uv](https://docs.astral.sh/uv/)** — встановлює anihub як окрему програму й сам завантажує Python 3.10+, якщо його немає. Замість uv підійде [pipx](https://pipx.pypa.io/latest/installation/).
2. **Відеоплеєр:** [mpv](https://mpv.io/installation/) (рекомендовано) або [VLC](https://www.videolan.org/), докладніше — у розділі [Плеєри](#плеєри).

Саме встановлення однакове на всіх ОС:

```shell
uv tool install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz
anihub tui
```

Посилання завжди веде на останній [реліз](https://github.com/0r1k/anihub/releases). Через pipx: `pipx install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz`.

Необов'язково — читання cookies з браузера (`--cookies-from-browser`, допомагає в рідкісних випадках з ddos-guard/cloudflare, залежність [rookiepy](https://github.com/thewh1teagle/rookie)):

```shell
uv tool install "anihub[cookies] @ https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz"
```

У rookiepy поки немає збірок під Python 3.14: на ньому встановлюйте anihub без цієї опції.

### Linux

```shell
curl -LsSf https://astral.sh/uv/install.sh | sh
sudo apt install mpv        # Debian/Ubuntu
sudo dnf install mpv        # Fedora
sudo pacman -S mpv          # Arch
uv tool install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz
```

### macOS

```shell
brew install uv mpv         # або VLC: brew install --cask vlc
uv tool install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz
```

mpv і VLC знаходяться й без `PATH`: anihub шукає їх у `/Applications/mpv.app` і `/Applications/VLC.app`.

### Windows

У PowerShell:

```powershell
winget install --id=astral-sh.uv -e
winget install --id=VideoLAN.VLC -e     # або mpv: scoop install mpv (https://mpv.io/installation/)
uv tool install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz
```

Запускайте у [Windows Terminal](https://aka.ms/terminal) (вбудований у Windows 11). VLC з `C:\Program Files\VideoLAN\VLC` знаходиться без `PATH`; шлях до іншого плеєра можна вписати в `F2` → «Команда плеєра» як є, з пробілами: `C:\Program Files\MPC-HC\mpc-hc64.exe`.

## Оновлення

```shell
anihub update
```

Команда перевірить останній реліз на GitHub, покаже, що нового, і попросить підтвердження `y/n`. Оновлення встановлюється тим самим способом, яким встановлено anihub (`uv tool`, `pipx` або `pip`).

- `anihub update -y` — без запитання
- `anihub update --force` — перевстановити, навіть якщо стоїть остання версія
- `anihub check-updates` — лише перевірити (anihub — на GitHub, бібліотеку anicli-api — на PyPI)

Під час кожного запуску anihub сам перевіряє, чи вийшла нова версія. Якщо вийшла, показує сповіщення й додає в нижній рядок клавішу `F9` «Оновити anihub»: вона лишається там, поки anihub відкритий. `F9` після підтвердження закриває anihub і запускає `anihub update` у тому самому терміналі. На Windows оновлення запускається в окремому вікні після виходу з anihub: запущений `anihub.exe` не можна перезаписати.

## Швидкий старт

```shell
anihub tui                              # відкрити
anihub tui -s anitube --search Бліч     # одразу шукати на anitube
anihub tui --ongoing                    # одразу відкрити онгоінги
anihub tui -q 720                       # якість (або найближча доступна)
```

Далі все робиться в інтерфейсі: `/` — пошук, `Enter` — відкрити тайтл, `Enter` на серії — обрати озвучення, `Enter` на озвученні — дивитися. `F2` — налаштування, `Ctrl+Q` — вихід.

## Інтерфейс

Повноекранний інтерфейс на [Textual](https://github.com/Textualize/textual), працює з клавіатурою й мишею. Мова (English, українська) змінюється в `F2` або ключем `--lang`, тема — в палітрі команд (`Ctrl+P` → Theme). Обидва вибори запам'ятовуються.

### Головний екран

Шість вкладок, перемикаються стрілками `←` `→` або клавішами:

| Клавіша | Вкладка |
|---|---|
| `/` | **Пошук** у поточному джерелі |
| `o` | **Онгоінги** з фільтром «Виходять» (за замовчуванням) / «Анонси» (серій на сайті ще немає; з датою прем'єри, якщо сайт її знає) / «Усі». Тайтли, в яких з минулого завантаження вийшла нова серія чи нове озвучення, піднімаються вгору з міткою `НОВЕ` |
| `w` | **Дивлюся**: ваш список Watching на MyAnimeList. Згори — тайтли з непереглянутими серіями (останні вийшли першими), далі — додивлені до останньої серії, що вийшла. Серії звіряються з сайтом, де ви дивитеся тайтл |
| `h` | **Історія**: якщо перегляд перервано, запропонує продовжити серію зі збереженого місця |
| `n` | **Сповіщення**: пов'язані тайтли (сиквели, приквели, фільми, спешли, спін-офи) до тайтлів зі статусом Watching, Completed чи On-Hold, яких ще немає у вашому списку. Найновіші в базі MyAnimeList — згори, додані за останній час позначено `НОВЕ`, кількість нових видно на вкладці. `a` — у Plan to Watch, `d` — приховати, `c` — позначити все прочитаним, `Enter` — відкрити тайтл |
| `m` | **MyAnimeList**: ваш список із фільтром за статусом і пошуком (`f`) за будь-якою назвою — ромадзі, англійською, японською чи назвою з сайту; регістр, пробіли й розділові знаки не важливі (`dr stone` знайде «Dr. Stone: Terraforming»). `Esc` очищує пошук. `Enter` відкриває тайтл на сайті, де ви його дивилися, або шукає його на поточному |

Загальні клавіші:

| Клавіша | Дія |
|---|---|
| `↑` `↓` | Переміщення списком, до рядка пошуку й вкладок |
| `Enter` | Відкрити тайтл |
| `r` / `F5` | Оновити поточну вкладку |
| `d` | Видалити тайтл з історії |
| `p` | Ваш профіль MyAnimeList |
| `F2` | Налаштування |
| `F9` | Оновити anihub (з'являється, коли вийшла нова версія) |
| `x` | Зупинити відтворення |
| `Ctrl+P` | Палітра команд, зокрема зміна теми |
| `Ctrl+Q` | Вихід |

### Сторінка тайтла

Ліворуч постер, далі список серій і список озвучень. У заголовку — назва й сайт, на якому відкрито тайтл: з «Історії», «Дивлюся» й «MyAnimeList» тайтл відкривається на сайті, де ви його дивилися, навіть якщо в `F2` обрано інше джерело.

| Клавіша | Дія |
|---|---|
| `Enter` | На серії — завантажити її озвучення (або озвучення всіх позначених); на озвученні — дивитися |
| Клік мишею | На серії — відкрити її озвучення, на озвученні — дивитися |
| `→` / `←` | До озвучень / назад до серій |
| `Пробіл` | Позначити серію, щоб подивитися кілька поспіль |
| `a` / `n` | Позначити всі / зняти позначки |
| `r` | Позначити діапазон: `1 3 5-10` |
| `F5` / `u` | Оновити список серій |
| `t` | Субтитри з інших сайтів |
| `o` | Той самий тайтл на інших сайтах: вікно відкривається одразу й заповнюється, щойно сайти відповідають. У знайдених — кількість серій і плеєри серії, `Enter` — відкрити тайтл там |
| `g` | Оцінка на MyAnimeList |
| `s` / `e` | Статус / кількість переглянутих серій на MyAnimeList |
| `l` | Прив'язати тайтл до іншого запису MyAnimeList |
| `D` | Видалити тайтл з вашого списку MyAnimeList |
| `Esc` | Назад |

Плеєри на сайтах різні: у yummy-anime майже все йде через Kodik (`kodikplayer.com`), в animego є ще AniBoom (часто 1080p), в anilibria — власний CDN. Якщо на поточному сайті потрібного плеєра чи озвучення немає, натисніть `o`.

Праворуч від кожного озвучення — найкраща доступна якість: вона підвантажується у фоні, по кілька плеєрів одночасно (`…` — ще вантажиться, `—` — плеєр не віддав відео, такий варіант не запуститься). Жирним — якщо якість не нижча за обрану в налаштуваннях. Отримані посилання на відео зберігаються 10 хвилин, тож запуск після цього починається одразу.

Хрестики в списку серій: зелений — позначено пробілом для перегляду поспіль, кольору акценту теми — серію вже переглянуто за MyAnimeList.

Злиті серії — ті, що отримали озвучення до офіційного виходу (вийшли 1–6, а на сайті вже є 12-та), — приховано: у заголовку списку видно «приховано злив: 12 (F2)». Показати їх можна в `F2` → «Показувати злиті серії».

Кілька серій поспіль граються плейлистом з обраним озвученням і плеєром, по 6 серій за раз (`F2` або `--m3u-size`). Якщо в наступної серії немає цього озвучення, перегляд зупиниться на останній доступній. Посилання на відео живуть близько доби, тож великі плейлисти не потрібні.

### Субтитри

Варіанти з оригінальною доріжкою та субтитрами позначено `СУБ`, і вони стоять першими в списку (вимикається в `F2`). Якщо на поточному сайті субтитрів немає, натисніть `t`: той самий тайтл шукається паралельно на всіх інших сайтах (до ~20 секунд). Назви на сайтах різні, тому тайтл шукається й за оригінальною назвою (з MyAnimeList або зі сторінки тайтла), а сезон звіряється в будь-якому записі: «2», «[ТВ-2]», «другий сезон», «Season 2». Щоб не підхопити інший сезон, для субтитрів тайтл береться лише за точного збігу: назва, оригінальна назва чи id MyAnimeList на сторінці тайтла. У вікні `o` показуються й схожі назви з позначкою «схожа назва, перевірте сезон».

Знайдені варіанти підписано сайтом, наприклад `СУБ Субтитри Morys · anitube «Блакитна скринька 2»`, і запускаються як звичайні. Сайти запам'ятовуються: у наступних серіях субтитри з них додаються самі. Перегляд зараховується на MyAnimeList тайтлу поточної сторінки.

### Постери

Постер береться з MyAnimeList, якщо тайтл прив'язано, інакше — обкладинка з сайту; у профілі так само показується аватар. Малює [textual-image](https://github.com/lnqs/textual-image) справжнім зображенням: через sixel (Windows Terminal 1.22+, Konsole, foot, WezTerm) або kitty graphics protocol (kitty, Ghostty). Якщо термінал не вміє ні того, ні іншого, постерів немає — замість піксельної мозаїки з кольорових блоків; у `F2` про це є підказка.

У вікні, вужчому за 110 колонок, постер ховається, вимкнути зовсім — `F2` → «Показувати постери на сторінці тайтла».

## Плеєри

Обираються в `F2` або ключем `--player`.

| Плеєр | Можливості |
|---|---|
| `mpv` (за замовчуванням) | Зараховує серію на MyAnimeList, якщо переглянуто від 80%, запам'ятовує місце для «Продовжити», закриття плеєра зупиняє перегляд кількох серій |
| `vlc` | Після закриття питає, чи зарахувати серію; перед наступною партією серій питає, чи продовжувати |
| `custom` | Будь-яка команда (`celluloid`, `haruna`, шлях до плеєра): посилання чи m3u-плейлист передаються останнім аргументом; поводиться як `vlc` |

**Відео через anihub** (`F2`, увімкнено за замовчуванням). Плеєр отримує відео не напряму з хостингу, а через anihub на `127.0.0.1`. Деякі хостинги, наприклад CDN Kodik, лишають без відповіді частину нових з'єднань. Плеєр на такому з'єднанні чекає свій тайм-аут (mpv — хвилину), а для HLS відкриває нове з'єднання на кожен 6-секундний фрагмент. Звідси довгий старт, зависання посеред серії й відео, яке не запускається взагалі. anihub тримає робочі з'єднання відкритими й перевикористовує їх, через 3 секунди без відповіді пробує нове з'єднання, а обірване завантаження продовжує з того самого байта. Якщо з якимось хостингом стало гірше, зніміть позначку: плеєр знову ходитиме на хостинг сам.

Плеєр шукається в `PATH`, а mpv і VLC — ще й у стандартних місцях встановлення (`/Applications/*.app` у macOS, `Program Files` у Windows). Додаткові аргументи плеєра — `F2` → «Додаткові аргументи плеєра» або `--player-args "--fullscreen"`.

## MyAnimeList

anihub веде ваш список на [MyAnimeList](https://myanimelist.net) через офіційний API v2:

- серія зараховується сама (mpv — якщо переглянуто від 80%, інші плеєри — після запитання)
- статус змінюється сам: перша переглянута серія — `Watching` (з `Plan to Watch`, `On-Hold`, `Dropped` або якщо тайтла немає в списку), остання — `Completed`. Тайтли в `Completed` не чіпаються, поки на сайті не ввімкнено повторний перегляд
- після останньої серії одразу відкривається вікно оцінки (`Esc` — оцінити пізніше)
- на сторінці тайтла: оцінка (`g`), статус (`s`), кількість серій (`e`), видалення зі списку (`D`), прив'язка (`l`)
- вкладки «Дивлюся» (`w`) і «MyAnimeList» (`m`) з пошуком у вашому списку (`f`)

**Профіль** (`p` на головному екрані) — як на сайті: аватар, статистика аніме й манґи з кольоровою смугою статусів, останні оновлення, улюблене, друзі. `Enter` на друзі відкриває його профіль, `l` — список аніме користувача (з позначкою, чи є тайтл у вашому), `u` — профіль за іменем, `b` — профіль у браузері, `a` на тайтлі — у ваш Plan to Watch. Профілі читаються з публічних сторінок сайту: API MyAnimeList інших користувачів не віддає.

**Сповіщення** (`n`) — замість сповіщень сайту «New Related Anime», яких немає в API: anihub сам перевіряє пов'язані тайтли вашого списку. Перша перевірка займає до хвилини (по запиту на тайтл), далі список пов'язаних кешується на добу. Музичні кліпи, промо-ролики й реклама не показуються.

**Підключення:**

1. Створіть API-клієнт на https://myanimelist.net/apiconfig → `Create ID`:
    - App Type: `other`
    - App Redirect URL: `http://localhost:8765/callback`
    - інші поля — будь-які
2. У `F2` вставте Client ID у розділ MyAnimeList і натисніть «Увійти». Відкриється браузер, після підтвердження він поверне вас в anihub. Якщо браузер на іншому пристрої або порт `8765` зайнятий — відкрийте посилання з вікна входу вручну, а адресу сторінки, куди вас перенаправило, вставте в поле вікна

**Прив'язка тайтлів.** Назви на сайтах локалізовані, тому anihub шукає запис MAL за оригінальною чи англійською назвою зі сторінки сайту (yummy-anime і частина тайтлів anitube одразу знають id MAL). Якщо точного збігу немає, на сторінці буде «Не прив'язано» — натисніть `l` і оберіть запис. Вибір запам'ятовується.

## Джерела

Обираються в `F2` → «Джерело» або ключем `-s`.

| Джерело | Мова | Особливості |
|---|---|---|
| `anitube` 🇺🇦 | українська | [anitube.in.ua](https://anitube.in.ua): озвучення й субтитри, варіанти підписано «Озвучення &lt;команда&gt;» / «Субтитри &lt;команда&gt;». Плеєри: fenixplay.xyz, moonanime.art, ashdi.vip, mp4upload — робочі йдуть першими. Частина плеєрів буває недоступна (ashdi сам сайт позначає тимчасово неробочим, moonanime і mp4upload блокуються в деяких мережах) — тоді оберіть інший плеєр або ввімкніть проксі в `F2` |
| `animego` (за замовчуванням), `yummy-anime`, `anilibria`, `animevost`, `dreamcast`, `hdrezka`, `sameband`, `anilibme` | російська | парсери з бібліотеки [anicli-api](https://github.com/vypivshiy/anicli-api) |

Якщо сайт закритий у вашій мережі, допомагає проксі: `F2` → «Проксі» або `--proxy socks5://user:password@host:port`.

## Налаштування й дані

Усе з `F2` зберігається одразу, кнопки «Зберегти» немає; тема й обрані фільтри теж зберігаються між запусками. Ключі командного рядка (`-s`, `-q`, `--player`, `--lang`, `--proxy` …) діють лише на поточний запуск.

| | Linux | macOS | Windows |
|---|---|---|---|
| налаштування | `~/.config/anicliru/` | `~/Library/Application Support/anicliru/` | `%APPDATA%\anicliru\` |
| дані | `~/.local/share/anicliru/` | `~/Library/Application Support/anicliru/` | `%APPDATA%\anicliru\` |

У Linux враховуються `$XDG_CONFIG_HOME` і `$XDG_DATA_HOME`.

- `settings.json` — налаштування, тема, MyAnimeList Client ID
- `mal_token.json` — вхід у MyAnimeList (доступ лише у вашого користувача; вийти — «Вийти» в `F2`)
- `history.json` — історія й місця для «Продовжити»
- `mal_links.json` — який тайтл на якому сайті прив'язано до якого запису MyAnimeList
- `ongoing.json` — які серії онгоінгів уже бачили (для мітки `НОВЕ`)
- `mal_feed.json` — кеш сповіщень: пов'язані тайтли, що прочитано й приховано
- `anihub.log` — помилки сайтів та інші логи (у термінал вони не пишуться)

## Довідка з команд

| Команда | Що робить |
|---|---|
| `anihub tui [OPTIONS]` | Запустити інтерфейс |
| `anihub update [-y] [--force]` | Оновитися до останнього релізу (див. [Оновлення](#оновлення)) |
| `anihub check-updates` | Перевірити, чи є нова версія |
| `anihub version` | Версії anihub і anicli-api |

Опції `anihub tui`:

- `-s, --source` — джерело: `animego`, `anitube`, `yummy-anime` … (за замовчуванням — з налаштувань)
- `-q, --quality` — якість відео, інакше найближча доступна (за замовчуванням 1080)
- `--search TEXT` — одразу шукати
- `--ongoing` — одразу відкрити онгоінги (разом із `--search` не можна)
- `-p, --player [mpv|vlc|custom]` — плеєр
- `--player-command TEXT` — команда плеєра для `--player custom`, наприклад `celluloid`
- `-pa, --player-args TEXT` — додаткові аргументи плеєра одним рядком: `"--fullscreen --no-audio"`
- `--lang [en|uk]` — мова інтерфейсу
- `--m3u-size INTEGER` — серій в одному плейлисті (за замовчуванням 6)
- `--timeout INTEGER` — тайм-аут HTTP, секунд (за замовчуванням 60)
- `--proxy TEXT` — проксі http(s)/socks4/socks5: `scheme://user:password@host:port`
- `--cookies-from-browser BROWSER` — взяти cookies з браузера (потрібен `anihub[cookies]`)
- `--cookies PATH` — cookies з файлу у форматі netscape
- `-H, --header Key=Value` — додати HTTP-заголовок (можна кілька разів)
- `--header-file PATH` — заголовки з файлу, по одному `Key=Value` на рядок

## Розробка

```shell
git clone https://github.com/0r1k/anihub
cd anihub
uv run anihub tui           # запустити з вихідного коду
uv tool install .           # встановити з вихідного коду
uv build                    # зібрати wheel і sdist у dist/
uv run python tests/smoke_test.py
```

- [anicli/tui/](anicli/tui/) — інтерфейс
- [anicli/common/](anicli/common/) — MyAnimeList, історія, плеєри, оновлення
- [anicli/extractors/](anicli/extractors/) — власні парсери сайтів (`anitube`); інші джерела беруться з [anicli-api](https://github.com/vypivshiy/anicli-api)

Пакет — чистий Python (`py3-none-any`): одна збірка працює на всіх ОС. CI ([build.yml](.github/workflows/build.yml)) на кожен пуш збирає його на Linux, macOS і Windows з Python 3.10, 3.12 і 3.14, встановлює через `uv tool install` і проганяє офлайн smoke-тест інтерфейсу ([tests/smoke_test.py](tests/smoke_test.py)).

### Випуск нової версії

Версія — `MAJOR.MINOR` (`7.2`, `7.3`, …):

```shell
# 1. підняти версію в pyproject.toml: version="7.3"
uv lock
# 2. закомітити й надіслати
git commit -am "anihub 7.3"
git push
# 3. тег = версія з літерою v
git tag v7.3
git push origin v7.3
```

[release.yml](.github/workflows/release.yml) перевірить, що тег збігається з версією в `pyproject.toml`, збере пакет, прожене smoke-тест і опублікує реліз з файлами та нотатками з комітів (їх можна відредагувати на сторінці релізу). Після цього `anihub update` у користувачів запропонує нову версію, а посилання встановлення почне вести на неї.
