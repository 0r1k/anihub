# anihub

Терминальное приложение для поиска и просмотра аниме с русской и украинской озвучкой или субтитрами. Работает на Linux, macOS и Windows.

- **9 источников:** animego, yummy-anime, anilibria, animevost, dreamcast, hdrezka, sameband, anilibme и украинский anitube 🇺🇦
- **MyAnimeList:** серии засчитываются сами, статус Watching / Completed ставится сам, оценка, удаление из списка, ваш список с фильтром по статусу
- **«Смотрю»:** ваши тайтлы из Watching, сверху — те, у которых вышли новые серии
- **Онгоинги:** фильтр «Выходят / Анонсы», тайтлы с новыми сериями поднимаются наверх
- **Субтитры:** метка `СУБ` у вариантов с оригинальной дорожкой и субтитрами; если на сайте их нет, `t` ищет тот же тайтл на остальных сайтах
- **Постеры** прямо в терминале, темы оформления, мышь и клавиатура, интерфейс на English, русском и українській
- **Обновление** одной командой: `anihub update`

## Установка

Нужно две вещи:

1. **[uv](https://docs.astral.sh/uv/)** — ставит anihub как отдельную программу и сам скачивает Python 3.10+, если его нет. Вместо uv подойдёт [pipx](https://pipx.pypa.io/latest/installation/).
2. **Видеоплеер:** [mpv](https://mpv.io/installation/) (рекомендуется) или [VLC](https://www.videolan.org/), подробнее — в разделе [Плееры](#плееры).

Сама установка одинаковая на всех ОС:

```shell
uv tool install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz
anihub tui
```

Ссылка всегда ведёт на последний [релиз](https://github.com/0r1k/anihub/releases). Через pipx: `pipx install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz`.

Опционально — чтение cookies из браузера (`--cookies-from-browser`, помогает в редких случаях с ddos-guard/cloudflare, зависимость [rookiepy](https://github.com/thewh1teagle/rookie)):

```shell
uv tool install "anihub[cookies] @ https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz"
```

У rookiepy пока нет сборок под Python 3.14: на нём ставьте anihub без этой опции.

### Linux

```shell
curl -LsSf https://astral.sh/uv/install.sh | sh
sudo apt install mpv        # Debian/Ubuntu
sudo dnf install mpv        # Fedora
sudo pacman -S mpv          # Arch
uv tool install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz
```

### macOS

```shell
brew install uv mpv         # или VLC: brew install --cask vlc
uv tool install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz
```

mpv и VLC находятся и без `PATH`: anihub ищет их в `/Applications/mpv.app` и `/Applications/VLC.app`.

### Windows

В PowerShell:

```powershell
winget install --id=astral-sh.uv -e
winget install --id=VideoLAN.VLC -e     # или mpv: scoop install mpv (https://mpv.io/installation/)
uv tool install https://github.com/0r1k/anihub/releases/latest/download/anihub.tar.gz
```

Запускайте в [Windows Terminal](https://aka.ms/terminal) (встроен в Windows 11). VLC из `C:\Program Files\VideoLAN\VLC` находится без `PATH`; путь к другому плееру можно вписать в `F2` → «Команда плеера» как есть, с пробелами: `C:\Program Files\MPC-HC\mpc-hc64.exe`.

## Обновление

```shell
anihub update
```

Команда проверит последний релиз на GitHub, покажет, что нового, и спросит подтверждение `y/n`. Обновление ставится тем же способом, которым установлен anihub (`uv tool`, `pipx` или `pip`).

- `anihub update -y` — без вопроса
- `anihub update --force` — переустановить, даже если стоит последняя версия
- `anihub check-updates` — только проверить (anihub — по GitHub, библиотеку anicli-api — по PyPI)

При запуске anihub сам проверяет обновления и показывает уведомление. На Windows обновление запускается в отдельном окне после выхода anihub: работающий `anihub.exe` нельзя перезаписать.

## Быстрый старт

```shell
anihub tui                              # открыть
anihub tui -s anitube --search Бліч     # сразу искать на anitube
anihub tui --ongoing                    # сразу открыть онгоинги
anihub tui -q 720                       # качество (или ближайшее доступное)
```

Дальше всё делается в интерфейсе: `/` — поиск, `Enter` — открыть тайтл, `Enter` на серии — выбрать озвучку, `Enter` на озвучке — смотреть. `F2` — настройки, `Ctrl+Q` — выход.

## Интерфейс

Полноэкранный интерфейс на [Textual](https://github.com/Textualize/textual), работает с клавиатурой и мышью. Язык (English, русский, українська) меняется в `F2` или ключом `--lang`, тема — в палитре команд (`Ctrl+P` → Theme). Оба выбора запоминаются.

### Главный экран

Пять вкладок, переключаются стрелками `←` `→` или клавишами:

| Клавиша | Вкладка |
|---|---|
| `/` | **Поиск** по текущему источнику |
| `o` | **Онгоинги** с фильтром «Выходят» (по умолчанию) / «Анонсы» (серий на сайте ещё нет; с датой премьеры, если сайт её знает) / «Все». Тайтлы, у которых с прошлой загрузки вышла новая серия или новая озвучка, поднимаются наверх с меткой `НОВОЕ` |
| `w` | **Смотрю**: ваш список Watching на MyAnimeList. Сверху — тайтлы с непросмотренными сериями (последние вышедшие первыми), затем досмотренные до последней вышедшей серии. Серии сверяются с сайтом, где вы смотрите тайтл |
| `h` | **История**: при прерванном просмотре предложит продолжить серию с сохранённого места |
| `m` | **MyAnimeList**: ваш список с фильтром по статусу и поиском (`f`): по любому названию — ромадзи, английскому, японскому или русскому с сайта; регистр, пробелы и знаки препинания не важны (`dr stone` найдёт «Dr. Stone: Terraforming»). `Esc` очищает поиск. `Enter` открывает тайтл на сайте, где вы его смотрели, или ищет его на текущем |

Общие клавиши:

| Клавиша | Действие |
|---|---|
| `↑` `↓` | Перемещение по списку, к строке поиска и вкладкам |
| `Enter` | Открыть тайтл |
| `r` / `F5` | Обновить текущую вкладку |
| `d` | Удалить тайтл из истории |
| `F2` | Настройки |
| `x` | Остановить воспроизведение |
| `Ctrl+P` | Палитра команд, в т. ч. смена темы |
| `Ctrl+Q` | Выход |

### Страница тайтла

Слева постер, затем список серий и список озвучек. В заголовке — название и сайт, на котором открыт тайтл: из «Истории», «Смотрю» и «MyAnimeList» тайтл открывается на сайте, где вы его смотрели, даже если в `F2` выбран другой источник.

| Клавиша | Действие |
|---|---|
| `Enter` | На серии — загрузить её озвучки (или озвучки всех отмеченных); на озвучке — смотреть |
| Клик мышью | По серии — открыть её озвучки, по озвучке — смотреть |
| `→` / `←` | К озвучкам / обратно к сериям |
| `Пробел` | Отметить серию, чтобы посмотреть несколько подряд |
| `a` / `n` | Отметить все / снять отметки |
| `r` | Отметить диапазон: `1 3 5-10` |
| `F5` / `u` | Обновить список серий |
| `t` | Субтитры с других сайтов |
| `o` | Тот же тайтл на других сайтах: окно открывается сразу и заполняется по мере ответа сайтов. У найденных — число серий и плееры серии, `Enter` — открыть тайтл там |
| `g` | Оценка на MyAnimeList |
| `s` / `e` | Статус / число просмотренных серий на MyAnimeList |
| `l` | Привязать тайтл к другой записи MyAnimeList |
| `D` | Удалить тайтл из вашего списка MyAnimeList |
| `Esc` | Назад |

Плееры у сайтов разные: у yummy-anime почти всё идёт через Kodik (`kodikplayer.com`), у animego есть ещё AniBoom (часто 1080p), у anilibria — собственный CDN. Если на текущем сайте нужного плеера или озвучки нет, нажмите `o`.

Справа от каждой озвучки — лучшее доступное качество: оно подгружается в фоне по несколько плееров сразу (`…` — ещё грузится, `—` — плеер не отдал видео, такой вариант не запустится). Жирным — если качество не ниже выбранного в настройках. Полученные ссылки на видео держатся 10 минут, поэтому запуск после этого начинается сразу.

Крестики в списке серий: зелёный — отмечено пробелом для просмотра подряд, цвета акцента темы — серия уже просмотрена по MyAnimeList.

Несколько серий подряд играются плейлистом по выбранной озвучке и плееру, по 6 серий за раз (`F2` или `--m3u-size`). Если у следующей серии нет этой озвучки, просмотр остановится на последней доступной. Ссылки на видео живут около суток, поэтому большие плейлисты не нужны.

### Субтитры

Варианты с оригинальной дорожкой и субтитрами помечены `СУБ` и стоят первыми в списке (выключается в `F2`). Если на текущем сайте субтитров нет, нажмите `t`: тот же тайтл ищется параллельно на всех остальных сайтах (до ~20 секунд). Русские названия на сайтах разные, поэтому тайтл ищется и по оригинальному названию (из MyAnimeList или со страницы тайтла), а сезон сверяется в любой записи: «2», «[ТВ-2]», «второй сезон», «Season 2». Чтобы не подцепить другой сезон, для субтитров тайтл берётся только при точном совпадении: название, оригинальное название или id MyAnimeList на странице тайтла. В окне `o` показываются и похожие названия с пометкой «похожее название, проверьте сезон».

Найденные варианты подписаны сайтом, например `СУБ Субтитры SubVost · yummy-anime «Голубая шкатулка 2»`, и запускаются как обычные. Сайты запоминаются: в следующих сериях субтитры с них добавляются сами. Просмотр засчитывается на MyAnimeList тайтлу текущей страницы.

### Постеры

Постер берётся с MyAnimeList, если тайтл привязан, иначе — обложка с сайта. Рисует [textual-image](https://github.com/lnqs/textual-image), способ выбирается в `F2` → «Отрисовка постеров»:

- **Графика** (по умолчанию) — лучшее, что умеет терминал: kitty graphics protocol (kitty, Ghostty), sixel (Konsole, foot, WezTerm), иначе цветные полублоки
- **Авто (без sixel)** — вместо sixel полублоки. Sixel выводится в терминал в обход интерфейса; если в вашем терминале интерфейс сдвигается или остаются артефакты, выберите этот режим
- **Цветные блоки** — всегда полублоками

В окне уже 110 колонок постер скрывается, выключить совсем — `F2` → «Показывать постеры на странице тайтла».

## Плееры

Выбираются в `F2` или ключом `--player`.

| Плеер | Возможности |
|---|---|
| `mpv` (по умолчанию) | Засчитывает серию на MyAnimeList при просмотре от 80%, запоминает место для «Продолжить», закрытие плеера останавливает просмотр нескольких серий |
| `vlc` | После закрытия спрашивает, засчитать ли серию; перед следующей пачкой серий спрашивает, продолжать ли |
| `custom` | Любая команда (`celluloid`, `haruna`, путь к плееру): ссылка или m3u-плейлист передаются последним аргументом; ведёт себя как `vlc` |

**Загрузка видео через anihub** (`F2`, включена по умолчанию). Плеер получает видео не напрямую с хостинга, а через anihub на `127.0.0.1`. Некоторые хостинги, например CDN Kodik, оставляют без ответа часть новых соединений. Плеер на таком соединении ждёт свой таймаут (mpv — минуту), а для HLS открывает новое соединение на каждый 6-секундный фрагмент. Отсюда долгий старт, зависания посреди серии и видео, которое не запускается вовсе. anihub держит рабочие соединения открытыми и переиспользует их, через 3 секунды без ответа пробует новое соединение, а оборванную загрузку продолжает с того же байта. Если с каким-то хостингом стало хуже, снимите галочку: плеер снова будет ходить на хостинг сам.

Плеер ищется в `PATH`, а mpv и VLC — ещё и в стандартных местах установки (`/Applications/*.app` в macOS, `Program Files` в Windows). Дополнительные аргументы плееру — `F2` → «Дополнительные аргументы» или `--player-args "--fullscreen"`.

## MyAnimeList

anihub ведёт ваш список на [MyAnimeList](https://myanimelist.net) через официальный API v2:

- серия засчитывается сама (mpv — при просмотре от 80%, другие плееры — после вопроса)
- статус меняется сам: первая просмотренная серия — `Watching` (из `Plan to Watch`, `On-Hold`, `Dropped` или если тайтла нет в списке), последняя — `Completed`. Тайтлы в `Completed` не трогаются, пока на сайте не включён пересмотр
- после последней серии сразу открывается окно оценки (`Esc` — оценить позже)
- на странице тайтла: оценка (`g`), статус (`s`), число серий (`e`), удаление из списка (`D`), привязка (`l`)
- вкладки «Смотрю» (`w`) и «MyAnimeList» (`m`) с поиском по вашему списку (`f`)

**Подключение:**

1. Создайте API-клиент на https://myanimelist.net/apiconfig → `Create ID`:
    - App Type: `other`
    - App Redirect URL: `http://localhost:8765/callback`
    - остальные поля — любые
2. В `F2` вставьте Client ID в раздел MyAnimeList и нажмите «Войти». Откроется браузер, после подтверждения он вернёт вас в anihub. Если браузер на другом устройстве или порт `8765` занят — откройте ссылку из окна входа вручную, а адрес страницы, куда вас перенаправило, вставьте в поле окна

**Привязка тайтлов.** Названия на сайтах русские и украинские, поэтому anihub ищет запись MAL по оригинальному или английскому названию со страницы сайта (yummy-anime и часть тайтлов anitube сразу знают id MAL). Если точного совпадения нет, на странице будет «Не привязано» — нажмите `l` и выберите запись. Выбор запоминается.

## Источники

Выбираются в `F2` → «Источник» или ключом `-s`.

| Источник | Язык | Особенности |
|---|---|---|
| `animego` (по умолчанию), `yummy-anime`, `anilibria`, `animevost`, `dreamcast`, `hdrezka`, `sameband`, `anilibme` | русский | парсеры из библиотеки [anicli-api](https://github.com/vypivshiy/anicli-api) |
| `anitube` 🇺🇦 | українська | [anitube.in.ua](https://anitube.in.ua): озвучення и субтитри, варианты подписаны «Озвучення &lt;команда&gt;» / «Субтитри &lt;команда&gt;». Плееры: fenixplay.xyz, moonanime.art, ashdi.vip, mp4upload — рабочие идут первыми. Часть плееров бывает недоступна (ashdi сам сайт помечает временно нерабочим, moonanime и mp4upload блокируются в некоторых сетях) — тогда выберите другой плеер или включите прокси в `F2` |

Если сайт закрыт в вашей сети, помогает прокси: `F2` → «Прокси» или `--proxy socks5://user:password@host:port`.

## Настройки и данные

Всё из `F2`, тема и выбранные фильтры сохраняются между запусками. Ключи командной строки (`-s`, `-q`, `--player`, `--lang`, `--proxy` …) действуют только на текущий запуск.

| | Linux | macOS | Windows |
|---|---|---|---|
| настройки | `~/.config/anicliru/` | `~/Library/Application Support/anicliru/` | `%APPDATA%\anicliru\` |
| данные | `~/.local/share/anicliru/` | `~/Library/Application Support/anicliru/` | `%APPDATA%\anicliru\` |

В Linux учитываются `$XDG_CONFIG_HOME` и `$XDG_DATA_HOME`.

- `settings.json` — настройки, тема, MyAnimeList Client ID
- `mal_token.json` — вход в MyAnimeList (доступ только у вашего пользователя; выйти — «Выйти» в `F2`)
- `history.json` — история и места для «Продолжить»
- `mal_links.json` — какой тайтл на каком сайте привязан к какой записи MyAnimeList
- `ongoing.json` — какие серии онгоингов уже видели (для метки `НОВОЕ`)
- `anihub.log` — ошибки сайтов и прочие логи (в терминал они не пишутся)

## Справка по командам

| Команда | Что делает |
|---|---|
| `anihub tui [OPTIONS]` | Запустить интерфейс |
| `anihub update [-y] [--force]` | Обновиться до последнего релиза (см. [Обновление](#обновление)) |
| `anihub check-updates` | Проверить, есть ли новая версия |
| `anihub version` | Версии anihub и anicli-api |

Опции `anihub tui`:

- `-s, --source` — источник: `animego`, `anitube`, `yummy-anime` … (по умолчанию — из настроек)
- `-q, --quality` — качество видео, иначе ближайшее доступное (по умолчанию 1080)
- `--search TEXT` — сразу искать
- `--ongoing` — сразу открыть онгоинги (вместе с `--search` нельзя)
- `-p, --player [mpv|vlc|custom]` — плеер
- `--player-command TEXT` — команда плеера для `--player custom`, например `celluloid`
- `-pa, --player-args TEXT` — дополнительные аргументы плеера одной строкой: `"--fullscreen --no-audio"`
- `--lang [en|ru|uk]` — язык интерфейса
- `--m3u-size INTEGER` — серий в одном плейлисте (по умолчанию 6)
- `--timeout INTEGER` — таймаут HTTP, секунд (по умолчанию 60)
- `--proxy TEXT` — прокси http(s)/socks4/socks5: `scheme://user:password@host:port`
- `--cookies-from-browser BROWSER` — взять cookies из браузера (нужен `anihub[cookies]`)
- `--cookies PATH` — cookies из файла в формате netscape
- `-H, --header Key=Value` — добавить HTTP-заголовок (можно несколько раз)
- `--header-file PATH` — заголовки из файла, по одному `Key=Value` на строку

## Разработка

```shell
git clone https://github.com/0r1k/anihub
cd anihub
uv run anihub tui           # запустить из исходников
uv tool install .           # установить из исходников
uv build                    # собрать wheel и sdist в dist/
uv run python tests/smoke_test.py
```

- [anicli/tui/](anicli/tui/) — интерфейс
- [anicli/common/](anicli/common/) — MyAnimeList, история, плееры, обновления
- [anicli/extractors/](anicli/extractors/) — собственные парсеры сайтов (`anitube`); остальные источники берутся из [anicli-api](https://github.com/vypivshiy/anicli-api)

Пакет — чистый Python (`py3-none-any`): одна сборка работает на всех ОС. CI ([build.yml](.github/workflows/build.yml)) на каждый пуш собирает его на Linux, macOS и Windows с Python 3.10, 3.12 и 3.14, ставит через `uv tool install` и прогоняет офлайн smoke-тест интерфейса ([tests/smoke_test.py](tests/smoke_test.py)).

### Выпуск новой версии

Версия — `MAJOR.MINOR` (`7.2`, `7.3`, …):

```shell
# 1. поднять версию в pyproject.toml: version="7.3"
uv lock
# 2. закоммитить и отправить
git commit -am "anihub 7.3"
git push
# 3. тег = версия с буквой v
git tag v7.3
git push origin v7.3
```

[release.yml](.github/workflows/release.yml) проверит, что тег совпадает с версией в `pyproject.toml`, соберёт пакет, прогонит smoke-тест и опубликует релиз с файлами и заметками из коммитов (их можно отредактировать на странице релиза). После этого `anihub update` у пользователей предложит новую версию, а ссылка установки начнёт вести на неё.
